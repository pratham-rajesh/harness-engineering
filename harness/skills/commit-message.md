---
name: commit-message
description: House style for writing a git commit message from a description of a change
---
Format: `<type>: <summary>` where type is one of feat, fix, docs, test, refactor, chore.
- Summary is imperative mood, lowercase, no trailing period, max 60 characters.
- Optional body after a blank line explains WHY, wrapped at 72 characters.
- Never mention the tool or assistant that wrote the change.
